# PineryZ Docs

Welcome to the PineryZ documentation.

PineryZ builds on-chain vault infrastructure for businesses that want to launch and manage their own vault products. VaultOS is the planned flagship product.

These docs are a starting point while the platform is under development. Product details will expand as the design settles.

## What you will find here

- An overview of PineryZ and how to read these docs
- Getting-started guidance for evaluating VaultOS
- VaultOS product direction (vision, not a production claim)
