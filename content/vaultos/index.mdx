# VaultOS

VaultOS is the vault a business offers under its own name. These pages are that product: how a vault is created, how it is operated, how it is listed, and what is built after the first release.

The pattern those pages build on is already running. It is on [The foundation](/vaultos/foundation).

## In this section

| Page | What it answers |
| --- | --- |
| [Create a vault](/vaultos/create-a-vault) | Name, symbol, and the asset the vault holds |

| [Registration](/vaultos/registration) | The check that lists a vault |
| [The build](/vaultos/build) | The work after the first release |
| [The foundation](/vaultos/foundation) | The deployment already running |
